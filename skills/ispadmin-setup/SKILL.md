name: ispadmin-setup
description: Help the user configure the local ISPAdmin plugin in Codex and verify read-only access.
---

Direct the user to Plugin → ISPAdmin → Gestisci → Collegamento ISPAdmin → Configura ISPAdmin. The masked form takes the HTTPS instance origin and API token. Never ask for a token in chat. Once saved, use the bundled ISPAdmin MCP tools for read-only requests.
